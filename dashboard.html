01

The business problem

Hosts largely price by intuition or by copying a neighbor's listing — which leaves money on the table in both directions. An underpriced entire-home listing loses revenue every booked night; an overpriced one just sits vacant. This project builds a data-driven reference price — "what does a listing like this typically go for?" — a host or a pricing team can check a listing against.

02

09

Limitations & what's next

  • This 2019 snapshot has no bedroom, bathroom, or amenity counts — a production pricing tool would use a fuller Inside Airbnb export.
  • Runs on DuckDB for zero-setup reproducibility; sql/snowflake_schema.sql is ready for a real Snowflake account.
  • Data is from 2019 — a refreshed pull would better reflect current pricing.
  • A gradient-boosted model (XGBoost/LightGBM) is the natural next iteration once the feature set is richer.
